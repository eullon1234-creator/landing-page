# 📋 CHECKLIST DE INFORMAÇÕES DO CLIENTE — LANDING PAGE DENTISTA

Este documento lista **tudo o que você precisa coletar do dentista/clínica**
antes de personalizar e entregar o site.

Após coletar as informações, preencha o arquivo **`config.js`** com os dados.

---

## ✅ COMO USAR ESTE CHECKLIST

1. Envie este formulário para o dentista **antes** de começar
2. Colete todos os itens marcados com 🔴 (obrigatório)
3. Colete os marcados com 🟡 (recomendado) se possível
4. Itens 🟢 (opcional) são bônus que enriquecem o site

## 📢 COMO ENVIAR PARA O CLIENTE

Você pode usar este checklist de três formas:

### Opção 1 — Enviar como documento
Envie este arquivo em PDF ou Word para o dentista preencher e devolver.

### Opção 2 — Google Forms
Crie um formulário Google com as perguntas organizadas por bloco.

### Opção 3 — Reunião presencial ou videochamada
Realize uma sessão de coleta de 30-60 minutos com o cliente, passando por cada bloco.
