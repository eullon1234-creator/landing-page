1. Introdução

A [NOME DA CLÍNICA], localizada em [ENDEREÇO COMPLETO], é responsável pelo tratamento dos dados pessoais coletados através deste site, em conformidade com a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018).

2. Dados Coletados

Coletamos os seguintes dados pessoais através do formulário de agendamento:

  • Nome completo
  • Número de telefone / WhatsApp
  • Endereço de e-mail (opcional)
  • Informações sobre o tratamento de interesse

Não coletamos dados sensíveis de saúde através do formulário neste site. Informações clínicas são coletadas somente durante a consulta presencial.

3. Finalidade do Tratamento

Os dados coletados são utilizados exclusivamente para:

  • Agendamento de consultas e avaliações
  • Comunicação sobre confirmação de horários
  • Envio de informações relevantes sobre tratamentos (mediante consentimento)

4. Compartilhamento de Dados

Seus dados não são vendidos, alugados ou compartilhados com terceiros para fins comerciais. Podemos compartilhá-los com prestadores de serviços necessários para o funcionamento da clínica (ex: plataformas de agendamento), sempre sob acordos de confidencialidade.

5. Retenção de Dados

Os dados pessoais são mantidos pelo tempo necessário para a prestação do serviço odontológico e conforme exigido pela legislação aplicável (CFO e legislação de saúde).

6. Seus Direitos (LGPD)

Você tem direito a:

  • Confirmar a existência de tratamento dos seus dados
  • Acessar seus dados pessoais
  • Corrigir dados incompletos, inexatos ou desatualizados
  • Solicitar a exclusão dos seus dados
  • Revogar o consentimento a qualquer momento
