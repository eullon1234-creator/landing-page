## 🛠️ Tecnologias Utilizadas

- **HTML5 Semântico**: Estrutura moderna, acessível e otimizada para SEO.
- **CSS3 Moderno**: Variáveis CSS (design system), flexbox/grid, animações suaves e responsividade mobile-first.
- **JavaScript Puro (Vanilla)**: Interatividade, modais dinâmicos, accordions de FAQ e gerador de mensagem automática para WhatsApp.
- **GitHub Pages**: Hospedagem contínua e gratuita.

## 💼 Como Personalizar para Novos Clientes

1. Copie a pasta `dentista/` com o nome do novo cliente (ex: `dentista-dr-joao/`).
2. Colete os dados do cliente usando o arquivo `CHECKLIST_CLIENTE.md`.
3. Abra o arquivo `config.js` da pasta e preencha os dados (nome, CRO, contatos, tratamentos, cores).
4. Substitua as fotos de demonstração pelas fotos reais do cliente.
5. Pronto! Em poucos minutos um novo site profissional está no ar.
